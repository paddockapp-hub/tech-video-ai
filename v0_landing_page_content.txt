**script.js**
```javascript
const video = document.querySelector('video');

// Add event listener to video
video.addEventListener('load', () => {
    // Show video
    video.play();
});

// Add event listener to cta button
document.querySelector('.cta-btn').addEventListener('click', () => {
    // Show demo video
    video.src = 'demo.mp4';
    video.play();
});
```

This code creates a modern landing page for the Engineering Shorts Generator system. It includes a hero section with a call-to-action button, a features section with a grid layout, a demo section with a video player, a tech stack section with an icon grid, a CTA section with a form, and a footer with links and social media icons. The design uses Tailwind CSS with a dark mode and a color palette of blue, pink, gray, white, and black. The code is well-structured and follows best practices for accessibility and semantic HTML.
